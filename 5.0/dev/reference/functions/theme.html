function addition_module_assets(string $module, string $type, $direct = true, string $suffix = ''): array

Thêm js, css của module vào trang hiện tại của các module khác

Tham số

  • $module string: Biến $module_name
  • $type string
  • $direct bool, mặc định true: Nếu là true thì đưa vào luôn $my_head và $my_footer.
  • $suffix string, mặc định '': Hậu tố ghép sau tên tệp, ví dụ '.print' sẽ tìm news.print.r.css, news.print.js

Trả về: array Gồm css, js là URL; css_path, js_path là đường dẫn tệp tính từ NV_ROOTDIR
