Danh sách hook ​

Danh sách được sinh từ các lời gọi nv_apply_hook trong mã nguồn. Hàm xử lý nhận $vars là mảng dữ liệu đầu vào, $from_data là thông tin module nguồn, $receive_data là thông tin module nhận.

Hook hệ thống ​

before_rss_output_xml ​

Trước khi xuất dữ liệu RSS hoặc Atom

  • Nguồn: Hệ thống
  • Vị trí: src/includes/core/theme_functions.php:400

Dữ liệu đầu vào ($vars)

  • $vars[0] là $channel array: Thông tin kênh
  • $vars[1] là $items array: Các mục tin
  • $vars[2] là $xsl string: URL file XSL
  • $vars[3] là $type string: rss hoặc atom
  • $vars[4] là $timemode string: GMT hoặc ISO8601

Giá trị trả về

  • Hàm xử lý trả về array: [$channel, $items, $xsl, $type, $timemode]
  • Gán vào [$channel, $items, $xsl, $type, $timemode]
  • Mặc định khi không có hàm xử lý hoặc hàm xử lý trả về null: [$channel, $items, $xsl, $type, $timemode]

Ví dụ

php
nv_add_hook($module_name, 'before_rss_output_xml', $priority, function ($vars, $from_data, $receive_data) {
    $channel = $vars[0];
    $items = $vars[1];
    $xsl = $vars[2];
    $type = $vars[3];
    $timemode = $vars[4];

    // Xử lý tại đây

    return [$channel, $items, $xsl, $type, $timemode];
});
