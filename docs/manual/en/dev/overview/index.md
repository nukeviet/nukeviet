# Part 1: Overview

This part gives new developers the big picture of NukeViet 5 before writing code: what the system is made of, where code lives, and which steps a request goes through.

1. [Concepts](./concepts.md): module, virtual module, function, block, theme, layout, plugin and hook, cronjob, languages, groups and permissions
2. [File and directory structure](./structure.md): root directory, `includes/`, `modules/`, `themes/`, `data/`, structure of a module and a theme
3. [Request lifecycle](./request-lifecycle.md): on the site and in the admin area, from `index.php` to the returned HTML

::: tip Read in order
Each article uses the terms of the previous one. If you have never worked with NukeViet, read all three before moving on to [Part 4: Programming](/dev/programming/index.md) (Vietnamese only for now).
:::
