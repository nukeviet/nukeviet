# Phần 1: Tổng quan

Phần này giúp lập trình viên mới nắm bức tranh chung của NukeViet 5 trước khi viết code: hệ thống gồm những thành phần nào, code nằm ở đâu, và một request đi qua những bước nào.

1. [Các khái niệm](./concepts.md): module, module ảo, function, block, theme, layout, plugin và hook, cronjob, ngôn ngữ, nhóm và quyền
2. [Cấu trúc file và thư mục](./structure.md): thư mục gốc, `includes/`, `modules/`, `themes/`, `data/`, cấu trúc một module, một theme
3. [Vòng đời một request](./request-lifecycle.md): ngoài site và trong khu vực quản trị, từ `index.php` tới lúc trả HTML

::: tip Đọc theo thứ tự
Bài sau dùng thuật ngữ của bài trước. Ai chưa từng làm với NukeViet nên đọc hết ba bài rồi mới sang [Phần 4: Lập trình](../programming/index.md).
:::
